# Интерфейс и стили

- Используй Tailwind CSS 4 и существующие utility-классы в JSX. Глобальные
  переменные и базовые стили держи в `app/globals.css`.
- Сохраняй русскую локаль интерфейса и форматирование денежных значений через
  `Intl.NumberFormat("ru-RU", ...)`.
- Поддерживай три состояния dashboard: загрузка, ошибка и результат без платежей
  либо с данными.
- Для внутренних переходов используй `next/link`.
- Интерактивные элементы должны быть нативными HTML-элементами и иметь понятный
  текст. Сообщение об ошибке должно сохранять `role="alert"`.
- Учитывай существующие адаптивные классы Tailwind при изменении раскладки.
