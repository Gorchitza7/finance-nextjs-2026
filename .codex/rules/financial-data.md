# Финансовые данные и расчёты

- Вся финансовая логика живёт в `app/lib/revenue.ts`; интерфейс не должен
  повторять нормализацию или конвертацию.
- Загружай источники платежей и курсы параллельно через `Promise.all`.
- Сохраняй `cache: "no-store"`: сводка использует актуальные данные при каждом
  запросе страницы.
- Нормализуй коды валют в верхний регистр и проверяй формат входных записей до
  расчёта.
- Складывай деньги в минимальных единицах: текущая логика использует центы и
  `Math.round`, чтобы избежать ошибок чисел с плавающей точкой.
- Курсы выражены как количество единиц валюты за 1 USD. Конвертацию выполняй
  через USD и проверяй наличие курса для исходной и целевой валюты.
- Ключ API получает только сервер из `FINANCE_API_KEY`; не передавай его в props,
  URL или клиентский код.
