# Качество и проверка

- TypeScript работает в строгом режиме. Не отключай проверки типов и не
  используй `any`, если можно описать тип данных.
- В проекте нет настроенного тестового раннера. Не добавляй тестовую
  инфраструктуру без отдельной задачи.
- После изменения кода запускай `npm run lint` и `npx tsc --noEmit`.
- Для production-проверки запускай `npx next build --webpack`. В этой среде
  Turbopack может завершиться ошибкой при обработке CSS из-за ограничения
  локального процесса; проверка через webpack уже совместима с проектом.
- Перед завершением убедись, что не изменены файлы, не относящиеся к задаче.
