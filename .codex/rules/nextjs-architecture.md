# Next.js: архитектура и данные

- Проект использует App Router. Корневой маршрут находится в `app/page.tsx`, а
  общие HTML-атрибуты, metadata и глобальные стили — в `app/layout.tsx`.
- Компоненты являются серверными по умолчанию. Добавляй `"use client"` только
  компонентам, которым нужны обработчики событий, hooks или браузерные API.
- Загружай внешние данные и читай `process.env` на сервере. В клиентский
  компонент передавай только сериализуемый результат через props.
- Для текущей сводки сохраняй `connection()` перед запросом: данные должны
  вычисляться во время запроса. `Suspense` оставляй вокруг серверной части,
  чтобы сохранить fallback загрузки.
- Ошибки загрузки преобразуй в понятное сообщение для `RevenueDashboard`.
  Для повторной загрузки используй `router.refresh()`.
- Обновляй `metadata` в `app/layout.tsx`, если меняется назначение страницы.
